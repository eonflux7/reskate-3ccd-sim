# Skate HVX Sim

Companion plugin for the Skate HVX Sim ReShade effect. It can hide the HUD so it doesn't go through the
camera look, and hold the game's FOV for a lens. Both stay off until you turn them on, and the FOV goes
back when you turn it off. The effect itself is installed separately.

Toggle it on the **HVX SIM** menu page or with the rebindable input (default LB + R3).
